# 批改发布、批注与错误演示实施计划

## 目标

在不改变现有评分业务的前提下，完成以下闭环：

- 教师可在任务详情批量发布成绩，也可在单份详情发布或撤回。
- 未自动匹配的提交可从任务所属教学班选择学生并手动确认。
- PDF 只写入一个最终分数；批注必须来自评分证据或可在原文中定位的评语片段。
- 教师可生成并发布错误演示；学生只能查看已发布成绩关联的已发布演示。

## 验收标准

1. 已评分且已确认学生的提交，在任务详情出现“发布成绩”；任务级出现“批量发布成绩”。
2. 陈一鸣等教学班成员能出现在手动匹配下拉框中，匹配后可发布。
3. 同一份原始 PDF 每次生成报告仅出现一个分数；不会在封面学号处打勾。
4. 原文存在可靠错误证据时出现叉号/波浪线和对应批注；不存在可靠锚点时明确少标，不随机造标。
5. 教师可预览错误演示；发布成绩前学生不可见，发布后学生可播放并查看错误原因。
6. 线上后端、Worker 健康检查通过，关键 API 冒烟测试通过。
